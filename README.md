## Repository Structure
* `algorithms/` — Contains algorithm implementations. 
* `maze-map/` — Moving AI `.map` grid files.
* `maze-scen/` — Moving AI `.scen` scenario files.
* `images/` — Output directory where generated search visualization plots are saved.
* `dataloading.py` — Data parsing, validation, and summary module.
* `visuals.py` — For generating search path visualizations.
* `main.py` — Main entry point for executing search and metrics.
